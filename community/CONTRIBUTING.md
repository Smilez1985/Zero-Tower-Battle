# Zero Tower Battle - Contributing Guide

## 🤝 How to Contribute

### Bug Reports
1. Check existing issues first
2. Provide environment details
3. Describe steps to reproduce
4. Attach screenshot/clip if possible

### Feature Requests
1. Submit via GitHub issues
2. Explain use case
3. Suggest implementation approach
4. Be specific about requirements

### Code Contributions
1. Fork repository
2. Create feature branch
3. Write tests for changes
4. Submit Pull Request
5. Follow coding standards

## 📋 Requirements for Contributions

- Must be pull request based
- Needs test coverage
- Follows code style
- Includes documentation

## 🎯 Good First Issues

- New enemy types
- UI polish
- Bug fixes
- Documentation updates
