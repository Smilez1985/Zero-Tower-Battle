# Zero Tower Battle - Frequently Asked Questions

### Q: What system requirements do I need?

### A: Raspberry Pi Zero 2W or later
- 512MB+ RAM
- SSD recommended
- Python 3.11+

### Q: Is this game online-only?

### A: No, works offline
- Single player fully offline
- Leaderboards optional

### Q: Can I play multiplayer?

### A: Coming in v1.3
- Server hosting planned
- Requires internet connection

### Q: How do I save my progress?

### A: Auto-save enabled
- Saves to `/tmp/game.db`
- No manual save needed

### Q: How do I report bugs?

### A: Use GitHub Issues
- Be descriptive
- Include steps to reproduce
