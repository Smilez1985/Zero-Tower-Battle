# Zero Tower Battle - Troubleshooting Guide

## 🔧 Common Problems & Solutions

### Game Won't Load

**Problem:** Game crashes on startup

**Solution:**
1. Check `/tmp/game.db` exists
2. Verify database permissions
3. Clear cache and restart

### Save Files Missing

**Problem:** No saves loaded

**Solution:**
1. Check `/tmp/game.db` permissions
2. Ensure directory writable
3. Verify database integrity

### Leaderboard Not Showing

**Problem:** Top scores empty or 0

**Solution:**
1. Verify API endpoint running
2. Check database connection
3. Ensure network access

### High Load Times

**Problem:** Slow game loading

**Solution:**
1. Close other applications
2. Clear `/tmp/` directory
3. Upgrade storage SSD
