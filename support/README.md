# Zero Tower Battle - Support

## 🛠️ Getting Help

### Reporting Issues

1. **First:** Check existing [Issues](../../.github/...)
2. **Search:** Forums for known problems
3. **Report:** Create new issue with details

### What to Include

- Raspberry Pi model
- Operating system version
- Steps to reproduce
- Error messages
- Screenshots/clips

### Known Issues

Load times vary by hardware.
Some achievements unlock slowly.
Multiplayer connectivity pending.
