# Zero Tower Battle - Usage Guide

## 👥 User Roles

### Developer
- Access to API documentation
- Build game server
- Implement features

### Player
- Play game locally
- View leaderboard
- Access settings

### Admin
- Manage server instances
- Monitor logs
- Configure settings

## 📊 Usage Scenarios

### Scenario 1: Single Player
- Install on Raspberry Pi
- Play game solo
- Track progress

### Scenario 2: Multiplayer
- Host game server
- Join friends
- Compete on leaderboards

### Scenario 3: Community
- Share achievements
- Participate in events
- Provide feedback

## 🎯 Use Cases

- Educational: Tower defense strategy
- Competitive: Leaderboard climbing
- Relaxing: Casual gameplay
- Testing: Performance benchmarks
